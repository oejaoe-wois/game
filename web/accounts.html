Credentials travel straight to the farm server and are stored AES-256-GCM encrypted — the server never returns them, not even masked passwords. Re-adding an email you already added = “fix my password”. The guild code (your guild's tag, name or numeric id) makes the worker verify the account's guild before every guild-dungeon run — an account only ever attacks its own guild's mobs, and a wrong code stops the dungeon farm with a clear audit entry. The dive targets turn the account into a DIVER: it hunts the named mobs first on every gate/wave/event page it sweeps (comma-separated, e.g. “goblin skirmisher, troll ravager” — with DIVE_ONLY=1 it hunts only those).
