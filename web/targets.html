Swarm attack · tick mobs, set the damage, swarm them one by one

Tick the live mobs above (or add guild-dungeon mob types below), type how much damage each account must deal to that type, and press Swarm: every account joins mob 1 and keeps slashing until each account banked its damage, then the whole fleet moves to mob 2, and so on — until no queued mob is left unattacked. Tick the same type twice (two instances) to swarm both ids back to back. Auto-refill keeps pulling fresh live instances of the queued types — mob ids churn every ~10 minutes, so this is what keeps a hunt alive. Quotas bank per account (mode each account) or across the whole fleet (mode combined).
