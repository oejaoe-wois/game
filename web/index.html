aio-farm

shared-target multi-account orchestrator · server-side containers

Sign in

Log in with your own username and password — you only see and control the game accounts you added yourself. (Ask the farm owner for a login.) Credentials are checked by the server and exchanged for a session token that is stored only in this browser (localStorage) — the panel repo holds zero secrets.

How the isolation works: every account runs as its own cookie-jar container on the farm server — separate sessions, parallel loops, one shared target bus. The game sees N normal sessions.

Risk note: game automation typically violates the game's terms of service; accounts farmed here can be banned. Keep JITTER_SCALE conservative.
